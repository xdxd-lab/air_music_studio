# 曲笛原型設計與驗收

曲笛原型用虛擬六孔和氣聲控制合成笛聲。相機模式由雙手的食指、中指、無名指各控制一孔。伸直開孔，彎下時左食指固定半孔，其他五指閉孔。不再提供半孔切換或可保留孔位的按鈕。

切換至「螢幕按孔」會開啟演奏區。手機橫放並讓主麥克風在左側時，六道透明色帶從畫面頂到底，從螢幕左邊起依序為左食指、左中指、左無名指、右食指、右中指、右無名指。右方留給設定、麥克風與色帶寬度，這一區不會觸發按孔。直放時以主麥克風朝下，六道色帶從下往上對應相同指法。

色帶寬度可選 50%、60%、⋯、150%，預設 100%。左食指色帶沿排列方向永遠是其餘各條的 1.5 倍；100% 為第一道 223.2 CSS px、其餘各 148.8 CSS px（舊版基準的 3.10 倍）。50% 為 111.6／74.4 CSS px，150% 為 334.8／223.2 CSS px。整組 100% 寬 967.2 CSS px。色帶不會自行縮小；超出畫面即裁切，控制列會浮到右上方，可從那裡調低寬度。不代表固定物理寬度。調整寬度、旋轉或重設視窗大小時，已按住的孔一律放開，不改麥克風狀態。

螢幕按孔可同時按多條，也可滑到相鄰色帶；手指離開或移出色帶即放開。鍵盤也可按住數字 1 到 6 對應相同的孔。曲笛面板預設展開，但不會自動開麥；可在設定或演奏區手動啟用，先保持安靜約一秒供背景校正。「返回設定」釋放所有按孔但保持麥克風狀態，可以看頻譜或改門檻；停用、收合主曲笛面板或離開頁面則會釋放麥克風，並恢復六弦模式。

音高維持原本的七個音級，不另外移調。左食指按下的 0.5 是固定覆蓋量，在原指法音階中視為按住，並不拿來內插半音；否則左食指會一直蓋過下面其他五指的作用。音高由最靠吹孔、首個未按的孔決定。依序從全開往下按，對應 F♯5、E5、D5、C5、B4、A4、G4。

## 氣聲與演奏

程式用時域 RMS 表示音量，再依 900–6500 Hz 頻帶在總能量中的占比、能量是否集中在單一頻點來估計寬頻氣聲。單靠音量容易受說話或拍手影響，單一高頻也容易被哨音或播放聲觸發。背景校正、靈敏度與遲滯降低持續背景聲和臨界點跳動的影響。近距離風扇、擦碰麥克風、齒擦音可能通過判斷。瀏覽器可忽略關閉降噪等音訊處理的偏好，需看實際裝置。原始麥克風訊號只進分析器，喇叭播放的是合成器輸出。 [W3C Web Audio](https://www.w3.org/TR/webaudio/) · [W3C Media Capture and Streams](https://www.w3.org/TR/mediacapture-streams/)

| 技巧 | 操作和限制 |
| --- | --- |
| 長音、強弱、連奏 | 持續氣聲維持音量，氣聲增強時音量與第二諧波增強。基音由孔位決定，連續改變指法會平滑換音。 |
| 指顫音與倚音 | 吹氣時快速交替按放指孔。採用簡化音列，筒音 G4，虛擬全開 F♯5；不模擬連續半孔滑音或實體曲笛全部叉指。 |
| 短氣分音、雙吐與花舌 | 分離的短氣可重新起音。分辨實際舌動、快速雙吐及花舌需要進一步取得演奏資料，並比較氣聲包絡、頻譜及每種技巧的誤判率。 |
| 超吹換八度 | 固定左三孔閉、右三孔開：普通氣聲合成 C5（約 523.25 Hz），高頻氣聲達門檻後基音切成 C6（約 1046.50 Hz），不是只增加第二諧波音量。這是實驗性音區控制，不是從人聲辨識音名。 |
| 循環換氣與笛膜 | 持續通過門檻可維持發聲。循環換氣沒有專用辨識。合成器以諧波近似笛聲，真實笛膜的非線性反應留待聲學建模。 |

曲笛的後續演奏研究可先以南派常見的倚音、指顫音與滑音作為操控測試，再測可辨識的分音速度。 [笛子共鳴與指法研究](https://caml.music.mcgill.ca/lib/exe/fetch.php?media=publications%3Aluan_dizi_jasa_2025.pdf) · [Jennifer Jo 的笛子演奏技法研究](https://escholarship.org/content/qt6mj8p1d2)

## 看頻譜調整高八度門檻

1. 戴耳機，用「螢幕按孔」固定指法，再按「啟用麥克風」。保持安靜約一秒，避免把吹氣當作背景音。
2. 用平常的力道吹，再試你想升八度時的氣流。圖上每條柱顯示那段頻率的峰值（dBFS，相對於數位滿刻度，並非環境音壓）。下方數字是「高頻／中頻」的功率比與實際音區。沒開麥時不收音；安靜時仍以約 11 Hz 更新圖，未通過氣聲門檻不會發音。
3. 預設以 1/4 作為上行門檻。如果不容易升，可依序嘗試 1/8、1/12、1/16、1/20、1/24、1/28、1/32；分母愈大，門檻愈低。如果太容易升，改回較小分母。先看自己普通與刻意加強高頻時的比值，再選兩者中間的門檻。不同裝置的麥克風、高頻響應與音訊處理不同，頻帶和門檻都還要實機調校。

判定以 1–3 kHz 為中頻、3–6 kHz 為高頻。把 FFT 分貝轉成線性功率，分別對兩區的頻點取平均，再扣掉校正時各區的背景功率（第 85 百分位）。使用平均是為了不讓較寬的高頻區因頻點較多而天然占優。中頻太接近底噪、無氣聲、指法遺失時不升音。取樣率不足 12 kHz 時保持本音，不用缺少高頻的資料猜測。跨過門檻至少 75 ms 才升高八度；回落至門檻的 75% 以下至少 100 ms 才降回，避免在邊界抖動。停止吹氣後重新起算。圖為輸入頻譜（未扣底噪），不使用合成器輸出。

## 實機驗收

- 在安靜環境校正後，分別輕吹、強吹、持續吹與短氣分音。記錄從吹氣到起音的延遲、放氣至停止的時間，再測說話、口哨、風扇、敲擊與喇叭回授的誤觸。
- 用螢幕孔位先檢查全開、全按、從左食指起逐孔、左食指固定半孔，以及同指法下氣量增強但比值未達門檻時維持本音、比值達門檻後確實升高一個八度，再加入相機。測試兩種手別、鏡像、橫直式、手指彼此遮擋、失去一隻手，以及維持氣流時的連奏和指顫音。
- 在 Android Chrome 橫放、直放測試第一條是否朝向麥克風，每個百分比可選；在狹窄裝置用 150% 時色帶不縮放，超出畫面部分裁切，右上方控制仍可點。測試多指按住、跨帶滑動、調整寬度、旋轉與取消操作後不留孔位。用實機長按確認演奏區不跳出選單，設定區仍可正常長按。
- 測試拒絕權限、切換分頁、停用後重新啟用及麥克風遭拔除。記錄實際的自動增益／降噪，以及可用靈敏度區間。

合成資料回歸：在 repo 根目錄執行 `node tests/check_flute_register.mjs`。測試載入網頁的完整程式並替換 DOM、Web Audio 與時間來源，檢查實際送往合成器的音高及畫面狀態；不取代手機麥克風或瀏覽器實測。
