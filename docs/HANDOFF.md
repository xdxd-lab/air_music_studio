# Air-Music Studio 開發交接

這份交接保存《分析空中撥弦網站版》分享副本中可讀到的更名、Pages 部署及 v0.3 設計決策，並對照 2026-11-27 查到的 GitHub 程式與部署。v0.1、v0.2 的原始開發經過以庫內的版本快照、[版本紀錄](../CHANGELOG.md)和[相機測試筆記](TESTING.md)為依據。

## 目前交接

- 正式基準為 [v0.4.2](https://github.com/xdxd-lab/air_music_studio/releases/tag/v0.4.2)，提交 `cd1d3e3`。正式站仍由 GitHub 的 `main` 部署。本次工作以草稿 PR 交接，從分支的 [index.html](../index.html) 繼續。
- 此次準備好的修改只有張掌止弦。手掌須在弦區連續維持 500 ms 才止弦，候選期間仍允許正常撥弦。原有的約 100 ms 放開緩衝仍保留。掉失追蹤或手掌移出弦區會讓下一段停留重新計算。
- 使用者表示整體工作尚未完全改好。這次沒有收到其餘要改的項目細節，接手時依使用者接下來提供的要求繼續。請先查看 [驗收清單](TESTING.md) 與 [曲笛設計](FLUTE.md)。

### 本機驗證資料

- [張掌止弦重現程式](../tests/check_palm_mute.py) 從當前 HTML 載入手掌判定、止弦及手勢分流，以合成骨架和模擬時間驗證 499 / 500 ms 邊界、候選期間撥弦、追蹤中斷後重新計時，以及關閉止弦開關後恢復。在儲存庫根目錄執行 `python3 tests/check_palm_mute.py`。程式用 Node.js 或 macOS 的 JavaScriptCore，無需攝影機。
- v0.4.2 發布前的模擬覆蓋六孔排列、多指按住、移動與取消、半孔開關，以及停止曲笛後清除接觸並恢復弦音。左三孔閉、右三孔開的模擬基音為 C5，八度泛音為 C6。手機實際多點觸控、權限、切換後的演奏手感，以及新的 0.5 秒張掌判定仍待實機驗收。

## v0.3 設計與程式對照

| 設計 | v0.3 實作 |
| --- | --- |
| 預設顯示 | 鏡像關閉。骨架、關節編號 0–20、空中選和弦及兩個解除限制開關開啟。相機與撥弦音效由使用者啟動。 |
| 手別與手指各自控制 | 兩個開關獨立，套用於撥弦與空中選和弦。例如基礎規則為右手中指時，依開關組合可得到右手中指、雙手中指、右手五指或雙手十指。兩個開關都關閉時，左手食指選和弦，撥弦預設右手食指，撥弦手可另選。未來手勢可沿用同一套規則。 |
| 同手的多個指尖可各自發聲 | 以追蹤到的手、指尖與琴弦分別記錄，同指同弦間隔 55 ms。不同指尖可在短時間撥動同一條弦。音訊壓縮器抑制疊加的尖峰。 |
| 螢幕和弦按鈕改變六弦頻率 | 預設 C，有 C、D、E、F、G、A、Am、Dm、Em、G7、C7、D7、Bm 與標準吉他調弦共 14 組。六條弦都可發聲，頻率以 A4 = 440 Hz 計算。可直接選擇並試聽六弦。換和弦只更新接下來的撥弦音高，先前發出的音繼續衰減。 |
| 空中選和弦後維持選擇 | 直式視窗的操作區在畫面底部，橫式在左方。指尖停留約 140 ms 選定，換和弦間隔至少 180 ms，移開後保留目前和弦。和弦區不觸發撥弦。螢幕、空中操作共用同一個和弦狀態。 |

分享對話的和弦示意以「標準調弦」展示。正式程式的初始選擇是 C，「標準調弦」保留為選項。三個時間值都是原型的起始值，手感待實測。

## 實機驗證與調校

- 優先在正式 HTTPS 網站以 Android Chrome 和桌面瀏覽器執行[驗收清單](TESTING.md)。先確認相機授權、前後鏡頭與停止釋放，再確認單手 21 點、雙手 42 點及手別與覆疊位置。另測試直橫切換、遮擋、背景恢復和 CDN 或模型載入失敗。
- 驗證兩個解除限制開關的四種組合、14 組六弦頻率、空中和弦的選擇與維持、和弦區隔離、同弦多指、上下掃弦、追蹤丟失後復原與靜止不誤觸。以前的 Android 截圖只證實獨立 WebRTC 對照頁可取得相機，以及下載的 v0.2 經 `content://` 開啟時被拒。
- 記錄裝置、瀏覽器、方向、影像解析度及模型 delegate。分別量測推論 FPS、動作到出聲的延遲、漏觸及誤觸，再評估 140 / 180 / 55 ms、越線閾值、遮擋時的追蹤連續性、手勢校準與掃弦手感。

## 尚未實作的構想

- **多樂器平台。** 以目前的 Strings（弦樂）作為第一個模組，規劃 Drums（打擊樂）、Keys（鍵盤樂器）與 Synth（合成器）。各模組共用雙手骨架追蹤、手勢規則和音訊引擎。v0.3 仍為單頁原型，模組拆分、共用介面與新增樂器尚待定義。
- **弦樂後續。** 可設定手勢閾值與校準、進一步調整撥弦速度及掃弦時序。探索以雙手捏合和拉伸建立動態琴弦，讓長度或張力影響音高，再處理放手與振動。現有固定六弦可作為比較基準，先用 2D／2.5D 的影像座標驗證。
- **進一步的音樂與效能功能。** 音階、MIDI、經使用者明確同意的錄音，以及 Web Worker／AudioWorklet 的效能研究。其他庫內路線見[工程架構](ARCHITECTURE.md#limits-and-roadmap)。
